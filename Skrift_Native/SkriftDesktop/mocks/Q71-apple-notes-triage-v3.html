What Skrift's importer does today, from source
  • Mac only: Import, then pick a folder of Apple Notes .md exports; each file becomes one note.
  • Title = the first # heading, else the filename.
  • Pictures in Attachments/ are copied and relinked; HEIC becomes JPEG.
  • Date: every note is dated to the import moment. D18 says it must be the creation date.
  • Every note copies the whole Attachments/ folder, not only its own pictures.
  • No choice per note, no memory: importing the same folder twice imports everything twice.
