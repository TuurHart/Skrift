3 · Share: which file carries them?

Two ways to put them in the PDF

A · The PDF in Library carries them

Every highlight and comment is written into the file you imported, as you make it.
  • Share sends the file as it is. Name unchanged: GFR grant application, draft 3.pdf.
  • If you open the file in Files or on the Mac, the highlights are already there.
  • The file you imported is changed for good. Removing a highlight rewrites it again.
  • Highlights live in two places: the synced record and the file. They must be kept in step.

B · Only the shared copy carries them Pick

Library keeps the file exactly as you imported it. Share makes a fresh copy with everything written in.
  • Share sends GFR grant application, draft 3 (highlights).pdf, built at that moment.
  • The synced highlight list stays the one truth (D207). The copy is made from it.
  • Opening the Library file in another app shows no highlights.
  • Share again later and the copy has your newest comments.
The question for you

When you share, should the PDF in your Library itself carry the highlights and comments (A), or only the copy you send (B)?

The mock defaults to B. Everything else on this page works either way.

4 · Choices you might overrule
  1. A comment is typed, short, and private to the highlight. It sits next to "Add note" and does not replace it: Add note is still the quote plus your voice, and becomes a Skrift note. Comment is a line of text that lives on the highlight and goes into the PDF.
  2. Your Skrift notes never go into the shared PDF. Only highlights and their comments do. A voice note made from a passage stays in Skrift, even when you share that PDF.
  3. A commented highlight shows a small badge, and the comment opens on tap. The reading view does not print comments inline under the paragraph, and the page view uses a sticky-note pin in the margin. Step 3 has a switch to see the inline version instead.
  4. Comment is the second item in the highlight's callout, between Copy and Remove highlight. Selecting fresh text still offers Copy · Highlight · ❝ Add note. To comment on new text you highlight it first, then tap it.

Under the hood (for the build item, not a decision): SourceHighlight gains an optional comment, synced the same way as today. On the page, the comment is the highlight annotation's text (the PDF Contents field), which is where PDF apps keep an annotation's note. How each other app (Preview, Acrobat, Files) displays it is unverified until a shared file is opened in them.
