# Capture-path gap hunt — the moment between Record and the note existing

2026-09-22. Scope: `SkriftMobile/Features/Recording/**`, `SkriftMobile/Services/Recording/**`,
`Shared/Recording/**`, `SkriftMobile/App/Intents/*`, `SkriftMobile/SkriftWidget/**`, the Live
Activity, `SkriftMobile/Services/Metadata* `+ `Shared/Metadata/LocationOneShot.swift`,
`Shared/Pipeline/{ASRPostProcess,Paragrapher,ImageMarkers}.swift`, and
`SkriftMobileTests/{LiveRecordingPrestart,LiveRecordingHandoff,LiveRecordingWatchdog,
LiveRecordingRouteChange,MemoSaver,Paragrapher}Tests`. 22 source files (~5,300 lines), read in
full, plus the SPEC clauses/required-differences named in the brief. Every verdict below is
from reading the code path, not from memory. Already-known bugs (D4 app-death loss, R19 photo
offsets, R46 disk-full) are cited where a scenario reaches them, never re-claimed as new.

### Consolidated candidates, ranked by impact

1. **Append vs. original-transcription race silently clobbers the appended text** — `MemoSaver.swift:573-671` (`appendRecordingAsync`) racing `MemoSaver.swift:792-837` (`runTranscription`); no gate on `MemoDetailView.swift:92`'s "Add recording" either. Whichever `repository.save()` lands second wins outright; the loser's clip is already deleted. Direct violation of D26. Fixture: `append-during-original-transcribe-race`.
2. **A failed audio merge on append silently keeps only the text, discards the audio** — `MemoSaver.swift:602`, zero log line (every sibling failure path in this file logs), clip deleted regardless of merge outcome. Fixture: `append-merge-fails-audio-lost`.
3. **`recoverStuckTranscriptions` can overwrite a diarized/user-edited transcript** — `MemoSaver.swift:864-880` has no `transcriptUserEdited` check; only reachable via a kill during an append (candidate 1's sibling failure mode). Fixture: `kill-mid-append-on-diarized-note`.
4. **`ImageMarkers.insert` reverses marker order on a position tie** — `Shared/Pipeline/ImageMarkers.swift:40-60`; violates C13; reachable from ordinary use (two photos in one pause, or a fast burst). No existing `ImageMarkersTests`. Fixture: `pic-during-pause-two-shots` / `pic-burst-same-offset`.
5. **A `.transcribing` memo orphaned on a now-gone device can never self-heal** — `MemoSaver.swift:860-862` + `Shared/Model/DeviceID.swift` (local-only id, not CloudKit-synced). Fixture: `stuck-transcribing-orphaned-device-gone`.
6. **A Control-Center/Siri "Record" tap on a never-opened install is silently dropped by onboarding** — `SkriftApp.swift:276-291` (`RootView.needsOnboarding`) vs `RecordingIntentBridge` (no expiry on the pending flag, unlike `prestart()`'s 8 s sweep). Violates C100. Fixture: `widget-tap-before-first-open`.
7. Already-known, reconfirmed present, not re-claimed: **R19** (interruption/call time isn't excluded from the photo-offset clock — `LiveRecordingService.handleInterruption`, `:920-945`, never sets `isPaused`, so `elapsed` keeps ticking through a call) and **R46** (`LiveRecordingService.swift:808`, disk-full `try?`).
