# Mac UI speed sweep (reader F), 2026-10-05

Top 3: (1) SidebarView.body re-derives the whole list (chip counts x4, two sorts, two full-corpus backlink text scans) on every click, every recording-meter tick and every run-progress tick (M1+M2). (2) Every keystroke in the Mac title field saves the CloudKit store and posts a notification that makes the sidebar re-fetch every Memo and every MemoEnhancement on the main thread (M4). (3) During playback each 20 Hz tick decodes the note's full word-timings JSON, re-splits the body and re-walks the text view (M5).
Static read only, nothing built or run; "suspect" marks anything where I read the call chain but the cost is an estimate. 2,000-note library assumed (~2,000 `PipelineFile` rows in `@Query`, ~2,000 `Memo` rows in the cloud store).
Prior rows in my area are re-checked in the last section.
