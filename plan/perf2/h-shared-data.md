# Shared data layer speed sweep (2026-10-05), reader h-shared-data

Top 3 by severity:
1. Mac reconcile sweep (every CloudKit import burst, app activation, launch): `adoptLateDiarization` faults every monologue's audio blob, plus a JSON parse+reserialize and two by-id fetches per note (rows M1-M3).
2. `NoteSnippet.plain` (5 full-body regex passes) runs on EVERY note in `ReminderScheduler.run` (launch, every foreground, every import burst) and in the per-note-open backlink scan (rows P1, P2).
3. Search lowercases every text field of every note on every keystroke (row S1).

Method: static read only. Nothing measured. "suspect" = I did not confirm the full call chain or the cost depends on a platform behaviour I could not check.
Paths are relative to `Skrift_Native/`. Library assumption: 2,000 notes, voice-memo transcripts 5-50 KB.
